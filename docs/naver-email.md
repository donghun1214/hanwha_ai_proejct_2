# 네이버 메일 발송 설정

방문자는 로그인 없이 수신 이메일을 입력합니다. 서버에 설정한 개인 네이버 메일 계정에서 발송합니다. Gmail·Resend 인증 정보는 사용하지 않습니다.

## 계정 설정

1. 네이버 계정 보안 설정에서 **2단계 인증**을 켭니다.
2. 2단계 인증 관리에서 **애플리케이션 비밀번호**를 발급합니다. 일반 로그인 비밀번호를 사용하지 않습니다.
3. PC 네이버 메일 → 환경설정 → POP3/IMAP 설정 → POP3/SMTP 설정에서 **사용함**으로 변경하고 저장합니다. 이 프로젝트는 SMTP 발송만 사용하며 메일을 읽거나 삭제하지 않습니다.
4. 프로젝트 `.env.local`에 다음 값을 직접 추가합니다. 실제 비밀번호를 채팅이나 Git에 남기지 않습니다.

```dotenv
NAVER_EMAIL=본인아이디@naver.com
NAVER_APP_PASSWORD=발급받은애플리케이션비밀번호
```

5. 개발 서버를 재시작합니다. 공개 배포 시에도 호스팅 서비스의 서버 환경 변수에 동일하게 설정합니다.
6. 작업 일정 생성 → 이메일 미리보기 → 수신 이메일 입력 → 발송으로 확인합니다. 네이버 외 다른 메일 서비스의 주소도 입력할 수 있습니다.

## 실행 환경과 발송 결과

- Node.js 서버에서 `smtp.naver.com:465`로 TLS 연결합니다. 배포 환경은 외부 SMTP 연결을 허용해야 합니다.
- 성공 표시는 SMTP 서버의 접수 완료를 뜻합니다. 최종 수신 여부는 수신함·스팸함에서 확인합니다.
- 중복 요청은 동일 서버 프로세스에서 최대 24시간 기록합니다. 재시작·다중 인스턴스 간에는 공유되지 않습니다. 여러 서버를 사용하는 경우 공유 저장소가 필요합니다.
- 시간 초과 등으로 접수 여부가 불명확하면 같은 요청을 자동 재발송하지 않습니다. 수신 여부를 확인한 후 처리합니다.
- 네이버의 발송량 제한과 계정 정책이 적용됩니다. 이 설정은 무제한 발송을 제공하지 않습니다.
