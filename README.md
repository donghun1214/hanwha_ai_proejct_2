# AI 작업 일정 최적화 서비스

현장 작업자가 다음 날 작업 일정을 빠르게 만들고 검토할 수 있도록 돕는 AI 일정 관리 서비스입니다.

사용자는 작업 목록과 작업별 소요 시간·장소·필요 인원, 작업자의 숙련도와 가용 인원을 입력합니다. 서비스는 여기에 다음 날 시간대별 날씨를 결합해 작업 순서와 시작 시간을 제안합니다. 결과 화면에서는 각 작업의 추천 시간, 위험도, 배정 인원, 추천 이유를 한눈에 확인할 수 있습니다.

## AI는 어디에 사용되나요?

일정 추천 과정에서 OpenAI의 `gpt-4.1-mini` 모델을 사용합니다. AI는 입력된 작업·인력 정보와 기상 데이터를 다음과 같이 함께 검토합니다.

- 작업의 장소, 시간, 우선순위와 위험 요소
- 작업마다 필요한 인원과 작업자의 숙련도
- 시간대별 기온, 체감온도, 강수량, 풍속

1. 외부 작업인지 내부 작업인지 구분합니다.
2. 비, 바람, 더위 같은 기상 조건이 작업에 미치는 영향을 확인합니다.
3. 작업 시간과 필요한 인원이 실제 가용 인력과 맞는지 비교합니다.
4. 겹치는 작업에 같은 작업자가 중복 배정되지 않도록 조정합니다.
5. 작업별 시작·종료 시간, 위험 점수, 판단 내용, 배정 작업자를 제안합니다.

AI가 만든 결과는 서버에서 작업 누락, 허용되지 않은 시간, 작업자 중복 배정을 다시 확인합니다. 따라서 AI 결과를 그대로 확정하는 것이 아니라, 관리자가 추천 근거를 확인하고 실제 현장 상황에 맞게 최종 결정할 수 있습니다.

AI가 추천한 일정과 배치 근거는 작업자와 관리자가 쉽게 확인할 수 있도록 공유용 메시지와 이메일 내용으로도 정리됩니다.

## 기상 데이터는 어떻게 사용하나요?

공공데이터포털의 기상청 단기예보를 사용합니다. 한화에어로스페이스 여수 사업장 주변의 내일 시간대별 기온, 습도, 강수량, 풍속을 받아 외부 작업 가능 여부와 위험도 판단에 반영합니다. 예를 들어 강수량이나 풍속이 높으면 외부 작업을 뒤로 미루거나 ‘주의’, ‘내부 우선’, ‘중단 검토’로 표시할 수 있습니다.

## 주요 기능

- 작업명, 장소, 예상 시간, 우선순위, 필요 인원 등록
- 작업자별 숙련도와 가용 인원 관리
- 기상청 단기예보를 기준으로 시간대별 작업 조건 표시
- AI 추천 일정, 위험 점수, 배치 근거, 작업자 배정 결과 제공
- 추천 일정 상세 확인 및 공유용 미리보기
- AI 결과를 공유용 메시지와 이메일 내용으로 정리
- 반응형 화면과 작업별 상세 판단 기준 제공

## 공유 기능 안내

문자 발송은 발신번호 인증이 필요해 현재 SOLAPI 연동을 보류 중입니다. 현재는 일정 내용을 확인하고 공유용 문구를 미리보기하는 기능까지만 제공합니다.
